# Experiment 15: Git Branching and Merge Conflict Resolution

## Overview
This experiment demonstrates how to collaborate in Git across multiple branches and resolve merge conflicts when concurrent changes are made to the same lines of code.

## Key Concepts
- Git Branching (`git checkout -b <branch>`)
- Parallel modifications
- Merge Conflicts (`git merge <branch>`)
- Conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`)
- Manual resolution, staging (`git add`), and final merge commit
