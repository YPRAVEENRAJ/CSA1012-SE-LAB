# Experiment 14: Collaborative Development via Git Fork & Pull Request Workflow

## Overview
This experiment demonstrates the open-source and collaborative **Fork-and-Pull Request (PR)** workflow using Git and GitHub.

## Tasks Covered
1. **Fork** an upstream public GitHub repository.
2. **Clone** the forked repository locally.
3. **Branch** creation (`feature/collaborative-enhancements`).
4. **Modify & Develop** utility features and unit tests.
5. **Commit & Push** changes to the remote fork.
6. **Open Pull Request (PR)** on GitHub targeting the upstream repository.
7. **Code Review & Feedback** simulation.
8. **Iterate & Commit** responses to review comments.
9. **Approve & Merge** the PR into the `main` branch.
10. **Submission**: Link to PR, summary of changes, and collaborative model explanation.
